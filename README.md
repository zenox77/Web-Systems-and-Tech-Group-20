# Tiktak — Browser-Based Time Tracker

Tiktak is a simple browser-based time tracking application that lets users log how they spend time across different projects. It was prepared for **Milestone 1: Interactive Frontend Web Application**.

## Features

- Live project timer with start, pause/resume, and stop/save controls
- Manual time entry with input validation
- Add and manage projects
- Daily summary for tracked time, completed sessions, and top project
- Time log with project filtering and delete controls
- Browser persistence using `localStorage`
- Responsive layout for desktop, tablet, and mobile
- User feedback through status badges, validation messages, empty states, confirmation prompts, and toast notifications

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Web Storage API (`localStorage`)

No backend or database is required for Milestone 1.

## Run locally

Open `index.html` directly in a browser, or use a simple local server such as VS Code Live Server.
